STEP 02真实居住与户籍

先别用“在哪个区补贴高”决定全家搬迁。

初中孩子转学后能否按相应资格报考杭州高中，必须先核实。2026年部分市区报考路径要求连续初中学习经历和学籍；余杭不能直接套用该招生范围。[S05]

01

给这家人的可执行判断

先让父亲验证业务与居住环境；全家是否同步搬，取决于两个孩子是否都有明确、连续的就读方案。

居住与创业 · 两条线同时查

城西与滨江都列入考察，不急着定唯一答案

余杭五常、仓前 / 未来科技城可作为城西工作生活候选；滨江长河、西兴可作为另一组候选。选择依据是孩子接收结果、真实合作对象、妻子工作和总通勤，不是大额政策标题。

城西有专项资金框架，滨江有已核到的数字贸易与小团队AI支持文件；这些是核验入口，并不证明本家庭能获资助。[S10] [S12] [S17]

搬家方式 · 先保留回旋余地

初中孩子资格未明，先试住，不先中断学业

我的方案是：父亲先短期考察或试住，孩子维持真实、连续的现有就读；收到接收与未来升学资格答复后，再安排正式长租和转学。

这不是建议长期两地分居，而是避免先退租、辞职、转出学籍，最后才发现目标路径走不通。

这里是基于已知家庭情况的决策建议，不是教育部门的录取意见。夫妻实际户籍、孩子年级及家庭预算尚不明，不能据此宣布某个区“保证最合适”。

02

先把会改变方案的前提写清楚

事项目前知道什么还要确认什么，为什么重要
父亲业务有出海App经历，继续做SaaS、自媒体等。是否有现成公司、真实AI产品、员工、研发和收入证明；决定能匹配哪类服务或申报。
母亲工作曾在民办学校任教，目前未确定下一份工作。学科、学段、学历、教师资格、职称、英语及合同诉求。不能把任教经历当人才认定结果。
孩子涉及小学和初中。逐个填写现年级、学籍、出生年月、拟迁学期；尤其确认是升初一，还是初中插班。
户籍与证件目前在西安生活。生活地不等于户籍地。逐一核对实际户籍、浙江居住证、人才居住证及杭州社保。
家庭与预算考虑全家租房常驻。家庭人数、卧室需求、教育支出、可承受月支出、现金储备及搬迁时点均待补齐。

把四个“地址”分开：实际居住地决定日常生活与相应居住材料；户籍地关联具体招生类别；公司注册/经营地影响惠企事项；社保缴纳地影响某些资格。它们不能互相替代。具体教育和创业条件见下方对应文件。[S04] [S07] [S08] [S13]

03

区域方案：每一组都有明确的成立条件

下面是居住考察方案，不是学校质量排名，也不是政策优劣评分。先拿到孩子的办理路径，再比较小区和办公室。

方案 A · 城西工作生活候选

余杭：五常 / 仓前 / 未来科技城

适用前提：实际合作对象或办公需求在城西，两个孩子均能按余杭当期规则接收，预算与接送距离合适。

创业先问：园区给出海软件小团队提供什么具体服务？余杭出海服务站建设相关政策如何落到当前可用服务？[S10] [S11]

关键空白：本次未可靠取得余杭最新转学及高中招生细则，因此不能把它写成“孩子上学已解决”的推荐。先经12345转余杭教育、招生及企业服务部门确认。

方案 B · 数字业务与条件型AI创业

滨江：长河 / 西兴

适用前提：业务伙伴、岗位或办公室实际在滨江；孩子接收与高中报考类别已核实。

创业先问：普通出海产品咨询数字贸易、软件服务与陪跑空间；确有AI产品的小团队，再核AI+OPC入库。[S12] [S13] [S17] [S18]

已核到：区级转学入口、教育咨询电话与工位政策解读。但有公开流程，不代表有空位，也不代表家庭已经满足条件。[S06]

方案 C · 由学校或工作位置反推

西湖：蒋村 / 三墩

适用前提：已经有明确的孩子接收路径，或母亲工作、父亲办公就在附近，且家庭能承受实际总成本。

创业先问：具体企业地址是否位于相应园区或专项资金范围，不能把全区都当成同一扶持范围。[S10]

不要预设：“租西湖、用余杭资源、直接享名校学位”不是可兑现的组合承诺。租房类别和学位仍按具体文件与实际审核处理。[S04]

我会怎么组织第一次实地看房

每组只选两套真正满足居住需求的房子，实测早晚接送两校 + 常用办公点的完整路线；不先花一天只看小区景观。地址附近的学校，只有获得接收确认后才算可用学校。

妻子工作未定时，不宜为了父亲每月几场活动让全家每天承担长通勤。若家庭住处和公司分属两区，分别核教育与创业规则，不假设两边条件可以拼接。

本次没有核验具体房源、成交租金或实时通勤，因此不提供“某小区三房多少钱、几分钟直达”的虚假精度。

04

两个孩子，各自走完一条完整路径

先定“新生”还是“转学生”

小学一年级新生 → P01；外地小学毕业升初一 → P02；小学或初中已经在读 → P03及目标区转学规则。不能互相替用。

再定“本家庭属于哪个资格类别”

分别核孩子户籍、儿童居住证、家长人才居住证等可用路径；不要只问“租房能不能读”，要提交一个完整的家庭事实组合。[S02] [S03] [S07]

有初中孩子，就同步问高中报考

把“是否可转入”“是否能按相应类别报考高中”“是否有名额分配资格”拆成三问；初二、初三尤其不应只拿小学招生问答判断。详细证据见P05。

最后核具体学校、学位、窗口和原校衔接

接收资格不等于指定学校名额。以拟迁学期公告和真实学位审核为准，接收明确后再与原校依法衔接，不做挂靠或虚构就读经历。

孩子实际阶段先拿到什么答复更稳妥的家庭动作
小学低中年级在读目标区转学资格、该年级空位、材料与时间。家长先考察，等接收路径清楚再转出。
小学六年级，准备初一外地小学毕业生升初的报名类别；从初一起就读后的升学路径。把搬迁时间与下一次正式新生招生对齐，而不是临时插班替代升初。
初一在读已在西安就读部分如何影响目标招生范围的连续学籍要求。不得假定“总共读满三年初中”就是“在规定范围连续三年”。
初二 / 初三高中报考类别与可行路径的明确核验；名额分配条件另问。暂不以全家立即迁居作为默认方案。教育路径不明确时，父亲先行测试更可逆。

上述是核验与搬迁建议，不是对任一孩子报考资格的个案裁定。升学规则依据拟毕业年度执行，2026年的规定只能作为当前风险识别依据。[S05]

P01教育历史基础规则，限小学一年级

小学积分入学：先确认是“入一年级”，还是“插班”

小学一年级 / 以拟入学区当年通知为准
2019年基础办法；2020-01-01起施行

原文关键词就读小学一年级
条款要点

办法要求儿童本人具备规定的有效居住证；家长积分用于排序。基础办法的积分截止点为4月10日；若为休息日，提前至此前最后一个工作日，积分不能跨区用于入学排序。最终还要看拟入学年度通知。 [S01] [S02]

对这家人的含义

这份政策不能拿来证明在西安读小学二、三年级的孩子能插班，也不能证明初中能转入。家长有居住证，不应直接当作孩子已满足证件要求。

办理前要确认什么

先写清每个孩子的出生年月、现年级和计划入学学期；若不是一年级新生，转到P03及目标区转学规则。

外地小学毕业升初：与初中在读转学不是同一条路径

2026年杭州市义务教育新生招生
2026-05-22发布的通知转引

原文关键词小学毕业生
条款要点

2026年招生通知允许符合条件的外地小学毕业生，向对应户籍或居住证所在区申请升初；具体由区级招生方案衔接。公办、民办报名和未录取后的安排也有顺序要求。 [S03]

办理前要确认什么

请区教育部门按孩子实际状态确认报名入口、材料、接收方式和下一学年时间。不要用2026年日期推定2027年的报名窗口。

落户与居住证：把历史依据和当前可办条件分开

市级基础规则；由公安窗口确认个案
杭政办函〔2023〕33号；2023-05-08起施行

原文关键词合法稳定住所
条款要点

2023年文件涉及大专、硕士、技能和积分等落户路径，也规定居住登记满半年且满足相应条件的居住证基础路径；未满16周岁儿童可依共同居住监护人的居住证申领。 [S07] [S02]

P07教育有办理机制，不保证指定结果

“长幼随学”是申请协调，不是任意指定学校

2026年义务教育招生与滨江转学办理
2026年通知口径

原文关键词长幼随学
条款要点

2026年招生通知提出落实长幼随学；滨江转学系统提供多孩绑定等选项。实际办理仍受所属区方案、接收条件和学位制约。 [S03] [S06]

P08创业资格未定，家庭预算暂按0元补贴

创业场地补贴：先过“人群”门槛，再谈租金上限

杭州市创业陪跑空间及符合规定的园外创业用房
杭人社发〔2025〕103号；2026-02-01施行

原文关键词重点人群创业者
条款要点

陪跑空间补贴面向在校生、毕业5年内高校毕业生、登记失业半年以上人员、就业困难人员、持证残疾人及自主就业退役军人。还看持股达到30%、在杭社保、入驻满6个月及首次补贴起点在注册5年内；在校生外的申请人不得由其他用人单位缴纳规定的职工保险。最高3元/㎡·天、50㎡、3年，低于上限按实际支出。 [S08]

对这家人的含义

父亲有创业经历，并不自动满足重点人群身份。创业办公租金不是全家住房租金；园区运营方的补助也不是入驻公司补助。不能将宣传上限直接计入家庭收入。

办理前要确认什么
